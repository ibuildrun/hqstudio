HQ Studio: установка по шагам

Вам понадобится около 30 минут. Ничего сложного делать не нужно: просто выполняйте шаги по порядку и нажимайте кнопки, как написано.

Что нужно заранее

  • Компьютер с Windows 10 или 11 (64 бит), 8 ГБ памяти и 15 ГБ свободного места.
  • Интернет.
  • Файл HQStudio-Setup.exe (вам его прислали).
Если сайты docker.com или github.com не открываются, включите VPN на время установки. После установки VPN нужен только для обновлений.

1Про Docker (ничего делать не нужно)

Docker - бесплатная программа, в которой будет работать ваш сайт. Сама она вам не понадобится, она просто должна стоять на компьютере.

Установщик HQ Studio поставит Docker сам, заранее ничего скачивать не нужно. Просто переходите к шагу 2.

Если автоматическая установка не сработала, поставьте Docker вручную: скачать Docker Desktop, установить (везде нажимать Accept/Ok), перезагрузить компьютер, запустить Docker и дождаться зелёного значка в углу окна. Подробности: docs.docker.com.

2Запустите установщик HQ Studio

  1. Дважды щёлкните по файлу HQStudio-Setup.exe. Первый запуск может занять до минуты: подождите, окно появится.
  2. Если Windows пишет «Система Windows защитила ваш компьютер»: нажмите Подробнее, затем Выполнить в любом случае. Это нормально для новых программ.
  3. Нажмите Начать. Слева видно, на каком вы шаге, справа - что делать. Назад можно вернуться кнопкой Назад.
  4. Docker. Установщик сам проверяет Docker. Если он не найден, нажмите большую кнопку Установить Docker автоматически: Windows спросит разрешение, нажмите Да. Подождите несколько минут. Если установщик попросит перезагрузить компьютер, перезагрузите и запустите HQStudio-Setup.exe ещё раз.
  5. Аккаунт. Введите своё имя и фамилию и придумайте пароль (не короче 8 символов). Это самый главный аккаунт: с него вы будете входить и управлять всем. Логин будет admin. Запишите пароль, восстановить его нельзя.
  6. Ключи. Эти поля можно оставить пустыми и просто нажать Далее. Их можно добавить позже (см. шаг 4).
  7. Нажмите Установить и подождите. Окно показывает, что происходит: копирование, скачивание сайта (при первой установке 3-10 минут), запуск, проверка. Закрывать его не нужно, свернуть можно.
  8. Когда появится зелёная галочка HQ Studio установлена, нажмите Запустить HQ Studio.
Если на каком-то шаге появилась красная ошибка, прочитайте подсказку под ней и нажмите Повторить. Если не получается, нажмите Сообщить об ошибке.

3Первый вход

  1. В окне программы введите логин admin и пароль, который вы придумали на шаге 2.
  2. Сайт открывается в браузере по адресу http://localhost:8080 (этот адрес работает на вашем компьютере). Его можно открыть и кнопкой в программе: раздел Сайт.
Если вы увидели программу и сайт, установка завершена. Остальные шаги нужны, только если вы хотите, чтобы сайт открывался у других людей.

4Адрес сайта для всех в интернете (по желанию)

По умолчанию сайт виден только на вашем компьютере. Чтобы им могли пользоваться клиенты, нужен публичный адрес. Для этого используется российский сервис Tuna.

  1. Зайдите на tuna.am и зарегистрируйтесь.
  2. В личном кабинете найдите и скопируйте свой токен (длинная строка букв и цифр).
  3. В программе HQ Studio откройте раздел Сайт и нажмите кнопку Ключи.
  4. Вставьте токен в поле Tuna, придумайте имя адреса латиницей (например mysite) и нажмите Сохранить.
  5. Через минуту в разделе Сайт появится адрес вида https://mysite.ru.tuna.am. Это и есть адрес вашего сайта для всех. Его можно скопировать кнопкой Копировать.

Ключ Gemini (для функций с искусственным интеллектом на сайте): получите его бесплатно на aistudio.google.com/apikey и вставьте в том же окне Ключи.

Компьютер должен быть включён, а Docker запущен, чтобы сайт работал для других людей.

Каждый день

  • Сайт запускается сам вместе с Docker после включения компьютера. Ничего нажимать не нужно.
  • Раздел Сайт в программе показывает, работает ли всё: зелёное Работает - всё хорошо. Там же кнопки Запустить, Остановить, Перезапустить и Логи.
  • Обновления. Слева в программе нажмите Обновления. Если есть новая версия, нажмите Обновить всё (или отдельно Обновить сайт / Обновить приложение) и подождите, пока полоса дойдёт до конца. Программа сама перезапустится.

Если что-то пошло не так

Нажмите Сообщить об ошибке (в установщике или в программе). Опишите проблему своими словами и нажмите Отправить. Программа попросит войти в GitHub (если нет аккаунта, там же можно бесплатно зарегистрироваться на github.com/signup). После этого сообщение попадёт к разработчику вместе с нужными техническими данными (пароли и ключи в них не попадают).
